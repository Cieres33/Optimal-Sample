## Get started
#### Requirement
- [Nod.js](https://nodejs.org/en/download/) >= 14.0.0
- [npm](https://www.npmjs.com/get-npm) >= 5.6.0
- Android Studio (for Android development)

#### Start the app
Web:
```bash
cd web
npm install
npx expo start --web
```
Android:
```bash
cd android
npm install
npx expo run:android
```
