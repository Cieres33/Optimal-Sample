## Optimal Sample Selector

使用贪心算法 + 局部搜索解决小规模子集覆盖问题。

适用范围：
- 样本总数 m: 45 ~ 54
- 选择样本数 n: 7 ~ 23
- 每组大小 k: 4 ~ 7
- 子集大小 j ≤ k
- 交集阈值 s ≤ j

## 安装依赖

```bash
npm install
```

## 运行测试

```bash
npx ts-node test.ts
```
